# Подтверждение удаления внутри сайта

Петя поручил исправить пропуски нажатия корзины и заменить браузерное подтверждение на окно сайта. Код до этого использовал window.confirm. Найден конфликт CSS: button:not(:disabled):active заменяет translateY(-50%) корзины на translateY(1px); при удержании область нажатия смещается примерно на половину высоты кнопки и mouseup может произойти снаружи.

Согласованный объём: стабильное положение корзины, HTML dialog с оформлением сайта, номером/целью заявки, предупреждением о невозможности восстановления, «Отмена» и «Удалить». Первоначальный фокус на отмене, Escape отменяет до запроса, фокус возвращается к корзине. showModal обеспечивает блокировку фона и клавиатурный фокус в окне. Во время DELETE обе кнопки заблокированы, Escape не закрывает окно; повторное нажатие не отправляет второй запрос. После успеха окно и карточка исчезают. Ошибка показывается внутри окна, возможны повтор либо отмена. Сервер/контракт удаления не меняются. Остальные системные подтверждения выхода/конфликта не затрагиваются.

Выбран native HTML dialog вместо div с ручной ловушкой фокуса: меньше собственного кода для доступности. Это элемент сайта, не window.confirm и не браузерный JS-диалог. Снятие transform-центрирования с корзины и top/bottom/margin обеспечивают стабильную область нажатия; для :active корзины отключается перемещение.

Проверка: регрессии появления/отмены/повторного открытия окна без window.confirm, Escape и возврат фокуса, задержка/ошибка/повтор, смена профиля/версия. В браузере: повторные нажатия/долгое нажатие, видимое окно сайта, отмена без DELETE, мобильная ширина. Backend уже проверен, не изменяется.
