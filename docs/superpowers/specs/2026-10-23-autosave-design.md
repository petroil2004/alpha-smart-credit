# Автосохранение заявки

Утверждено Петей в чате: продолжить codex/petya-need-assistant-ui, затем отправить один общий PR. Код и публикация PR разрешены, merge отдельно. Работа последовательно в текущей копии.

Цель: пользователь заполняет заявку без повторных нажатий сохранения. Термин «Черновик» остаётся статусом, остальной интерфейс говорит о заявке.

Подходы: ручная кнопка сохраняет нынешнее лишнее действие; периодический таймер может отправлять неизменённое и оставляет большой промежуток потери; выбран debounce 1500 мс после изменения плюс немедленная попытка при переходе шага. Явная отправка в банк остаётся отдельным будущим действием.

- Сохранять только изменённые корректные значения через действующий PATCH/version, без миграций и зависимостей. Пустое допустимо; невалидное не заменять null. Зависимую смену продукта и очистку его параметров отправлять одним обновлением.
- Один запрос сохранения за раз; новый ввод в процессе не теряется. Ответ обновляет серверную версию и список, но не заменяет введённые поля.
- Показать «Сохраняем…», «Есть несохранённые изменения», «Изменения сохранены», ошибку с повтором. Последнее только для подтверждённого актуального ввода.
- Сеть/422: не бесконечный цикл. Явный повтор или исправление ввода; 401 и 409 останавливают автоповторы до входа/загрузки серверной версии. Изменение компании исключает использование данных прежней компании.
- Фоновое сохранение не блокирует форму/калькулятор/шаги. При выходе из заявки/смене профиля дождаться очереди; если она не завершилась успешно, можно повторить либо явно отказаться от остатка. Сохранять предупреждение beforeunload для неподтверждённого ввода, без обещания сохранения при принудительном закрытии или без связи.
- Первые три шага: Назад/Продолжить без кнопки сохранения. Четвёртый: «Сохранить и выйти», ожидание подтверждения и список. Ошибка явного завершения показывает нужное поле/шаг, фоновая ошибка не уводит с текущего шага.
- «Открыть заявку», «Создать заявку», «Проверьте заявку», «Сводка заявки», «Версия заявки». Правая панель сохраняет структуру и объясняет автосохранение. DRAFT и API не переименовываются.

Вне объёма: подача, новые кредитные правила, офлайн-хранилище, работающая LLM. Кнопки целей/«Другое», буфер описания и заготовка помощника сохраняются.
