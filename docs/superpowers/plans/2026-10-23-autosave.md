## Review Focus
1. Input during a delayed save: newest raw text survives; next request uses returned version.
2. Invalid intermediate values: independent fields saved, incorrect value never cleared in DB.
3. 401/409/timeout and account changes: no loops or overwrites, no old callbacks applied to new scope.
4. Leave/final action while pending: waits latest input or explicitly confirms discard.
5. No-op/format-only edits and product mechanics: no repeated PATCH; dependent fields updated together.
