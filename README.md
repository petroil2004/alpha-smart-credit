# Умный кредитный кабинет предпринимателя

Командный проект хакатона Альфа-Банка: прототип кредитного процесса для малого бизнеса, связывающий кабинет предпринимателя и работу банковского сотрудника.

## Текущее состояние

Приложение находится на этапе проектирования. В репозитории подготовлены задания команды и общие договорённости. Код приложения и инструкции его запуска появятся отдельными Pull Requests; сейчас работающий кредитный кабинет ещё не реализован.

Согласованы три продукта: оборотный кредит, кредит на оборудование и упрощённый овердрафт. В прототипе будут кабинет клиента и рабочее место сотрудника, объяснимая балльная оценка риска, принятие предложения, моделирование подписания и предоставления финансирования. Ассистент подключается через локальную Ollama; первый кандидат модели — `qwen3:4b-instruct-2507-q4_K_M`. Модель пока не установлена и не проверена в рамках проекта.

## Работа с репозиторием

Используем короткую отдельную ветку `codex/имя-задача` от актуальной `main`. Изменения сохраняются осмысленными коммитами и предлагаются через PR. После проверки другим участником Петя или Витя объединяет их обычным merge. Подробности и команды — в Git-инструкции выше.

Для работы на своём компьютере получите репозиторий командой `git clone https://github.com/petroil2004/alpha-smart-credit.git` и откройте полученную папку. Не запускайте clone поверх уже существующей рабочей копии. Витя работает в собственной копии; у Пети рабочая папка этого чата уже связана с репозиторием через `origin`.

Для будущих задач Codex прочитает [AGENTS.md](AGENTS.md), содержащий общие правила проекта. Материалы от коллег сначала проверяются, затем включаются в общую версию; чат не заменяет актуальные файлы репозитория.

Все демонстрационные компании, финансовые сведения и операции будут синтетическими. Реальные банковские операции не выполняются.
