# Frontend

React + TypeScript + Vite. Клиентский кабинет и рабочее место сотрудника используют один backend. Для проверки всего продукта используйте [корневой README](../README.md); [сценарии](../docs/jury/scenarios.md) и [API](../docs/jury/api-and-policy.md) описывают текущие возможности.

## Разработка

Нужен Node.js 22.12+ ветки 22 либо Node.js 24+ согласно package.json. Из каталога frontend:

```bash
npm ci
npm run dev
```

Vite по умолчанию работает на http://127.0.0.1:5173 и передаёт /api в backend на http://127.0.0.1:8000. Перед запуском проверьте существующие серверы. Для обычного запуска продукта Node.js на компьютере не нужен: сборка выполняется в Docker.

## Проверки

```bash
npm test
npm run build
```

Можно передать конкретные файлы: `npm test -- src/DecisionResult.test.tsx src/info-queue.test.ts`. Тесты интерфейса используют имитации API; проверки PostgreSQL выполняются отдельно в [backend](../backend/README.md).

## Устройство

Компоненты находятся в src/components, клиент API — в src/api.ts и src/info-api.ts. Сервер управляет правами, расчётами и допустимыми решениями. После пересчёта используется общая оценка заявки; итоговое решение отправляется только из окна подтверждения. Финансовый пульс получает рассчитанные сервером показатели, ассистент использует серверный каталог. Ключ модели в браузер не передаётся.
